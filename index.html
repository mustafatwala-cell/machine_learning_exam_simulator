أساسيات وأنواع الـ Machine Learning

التعريف والهدف: الـ Machine Learning هو فرع من الذكاء الاصطناعي Subset of AI True، وهدفه الأساسي تمكين الكمبيوتر من التعلم من البيانات To enable computers to learn from data بدون برمجة صريحة.
طبيعة البيانات والأخلاقيات: لا يقتصر على البيانات الرقمية فقط؛ فلو جاءك سؤال Can only be applied to numerical data فالإجابة False لأنه يطبق على الصور والنصوص والصوت. كما أن الموديلات المدربة على بيانات متحيزة Biased data لا يمكن اعتبارها عادلة أو موثوقة Fair and reliable False.
أنواع التعلم الأساسية (انتبه: لا يوجد نوع اسمه Structured Learning):
  • التعلم الخاضع للإشراف Supervised Learning: يتدرب على بيانات مصنفة Labeled data، وهدفه الأساسي تعلم دالة تربط المدخلات بالمخرجات المعروفة Learn a mapping from inputs to known outputs.
  • التعلم غير الخاضع للإشراف Unsupervised Learning: يتعامل مع بيانات غير مصنفة Unlabeled data ولا يخرج أبداً نتائج مصنفة (Always provide a labeled output False). أشهر أمثلته التجميع K-means Clustering وتقليل الأبعاد PCA.
  • التعلم المعزز Reinforcement Learning: يتعلم فيه العميل Agent عن طريق استقبال تغذية راجعة من البيئة By receiving feedback from the environment.
الفرق بين Classification و Clustering:

التصنيف Classification يحتاج بيانات مصنفة Requires labeled data، بينما التجميع Clustering لا يحتاج Does not.

الفرق بين Regression و Classification:

الـ Regression يتوقع قيماً رقمية مستمرة Continuous numerical values (مثل أسعار البيوت Predicting house prices)، بينما الـ Classification يتوقع فئات منفصلة Discrete values (مثل Email is spam or not ومن خوارزمياته Decision Trees).

تقسيم البيانات، مشاكل الموديل، ومقاييس التقييم Evaluation Metrics

تقسيم البيانات والتحقق: مصطلح Data Splitting يعني تقسيم البيانات إلى أجزاء للاختبار والتحقق. وظيفة الـ Validation data الأساسية هي ضبط الإعدادات To tune hyperparameters وتقليل الحفظ الزائد Reduce overfitting True.
التحقق المتقاطع: تقنية Cross-validation تُستخدم لتقسيم البيانات إلى مجموعات تدريب واختبار عدة مرات متتالية للتقييم Split data into training and test sets multiple times for evaluation.
مشكلة الحفظ الزائد Overfitting

الموديل معقد جداً ويتعلم الضوضاء من بيانات التدريب The model learns noise from the training data. ولتقليل التباين العالي Reduce variance نستخدم Regularization (أو Cross-validation).

مشكلة التبسيط المخل Underfitting

الموديل بسيط أكثر من اللازم ويفشل في التقاط أنماط البيانات Model is too simple and fails to capture the data patterns (يرتبط بـ High Bias).

مقاييس التقييم Evaluation Metrics (سؤال مؤكد):
  • مقاييس التصنيف Classification Metrics: تشمل Precision و Recall و F1-Score. (انتبه: Mean Squared Error (MSE) ليس مقياساً للتصنيف!).
  • مقاييس الانحدار Regression Metrics:
    • Mean Squared Error (MSE): الصيغة المستخدمة لتقليل مجموع مربعات الأخطاء بين القيم الحقيقية والمتوقعة Minimize sum of squared errors.
    • R-squared (R²): يقيس مدى قدرة المتغيرات المستقلة على تفسير التباين في المتغير التابع Explain the variance in the dependent variable.

خوارزميات الـ Regression وتقنيات الـ Regularization

الانحدار الخطي Linear Regression: يُستخدم لمسائل الـ Regression فقط ولا يصلح للتصنيف (Used for both classification and regression False). ومن افتراضاته الشائعة أن المشاهدات مستقلة عن بعضها The observations are independent.
الانحدار التدريجي Gradient Descent: خوارزمية تعمل على تقليل دالة التكلفة أثناء تدريب الموديل Minimizes a cost function during model training True.
الانحدار متعدد الحدود Polynomial Regression: أهم خصائصه أنه دائماً خطي بالنسبة للمعاملات It is always linear in terms of the parameters، ولكنه أكثر عرضة للحفظ الزائد More prone to overfitting than linear regression True.
التقنية نوع الغرامة والوظيفة هل يصفر المعاملات Zero؟
Ridge Regression (L2) يضيف غرامة على المعاملات الكبيرة Penalty for large coefficients لا يصفرها أبداً (Shrink to exactly zero False)
Lasso Regression (L1) يختار الخصائص المهمة تلقائياً Performing feature selection نعم، يصفر بعض المعاملات (Reduced to zero True)
Elastic Net Regression هجين يجمع بين Lasso and Ridge Regression ممتاز مع الخصائص المترابطة Multiple correlated features True

خوارزمية الانحدار اللوجستي Logistic Regression (أسئلة مضمونة)

نوعه ووظيفته: يُعتبر نموذجاً احتمالياً Probabilistic model True، ويُستخدم لحل مسائل التصنيف فقط Classification problem، ولا يُستخدم لتوقع قيم رقمية مستمرة (Predict continuous numerical values False).
دالة التحويل والفرضية: يستخدم دالة Sigmoid function لتحويل الفرضية Hypothesis إلى احتمالات Predict probabilities محصورة بين 0 و 1.
تفسير المخرج hθ(x): يمثل الاحتمال المقدر بأن الفئة تساوي 1 Estimated probability that the class is 1 True. إذا كان hθ(x) > 0.5 تكون الفئة المتوقعة هي 1، وإذا كان أقل من 0.5 تكون الفئة المتوقعة هي 0.
ثلاث معادلات ومصطلحات في الـ Logistic Regression تكررت في الميدتيرم:
  • العلاقة بين الاحتمال p والـ Odds هي: Odds = p / (1 - p).
  • المصطلح الذي يمثل تحويل الاحتمال Probability إلى Log-odds هو دالة Logit function، ووظيفة الـ Log of odds هي إزالة قيود المدى على القيم المتوقعة Remove range restrictions on predicted values.
  • تقنية Maximum Likelihood Estimation (MLE) تهدف إلى تعظيم دالة الاحتمال Maximize the likelihood function.

خوارزمية آلات المتجهات الداعمة Support Vector Machines (SVM)

النوع والهدف الرئيسي: الـ SVM هو خوارزمية Supervised learning True، هدفها تصميم مستوى فاصل يصنف البيانات لفئتين بأكبر هامش Design a hyperplane that classifies data into two classes with maximum margin.
المتجهات الداعمة ونوع المسألة الرياضية: النقاط الأقرب للمستوى الفاصل تُسمى Support vectors. وتحل خوارزمية الـ SVM مسألة تحسين من نوع Quadratic programming problem تهدف لتعظيم الهامش بين الفئات Maximize the margin between the classes.
معامل الغرامة Penalty Term: وظيفته في البيانات غير القابلة للفصل خطياً هي التعامل مع أخطاء التصنيف To handle misclassifications.
خدعة النواة Kernel Trick والـ Non-linear SVM:
  • تُستخدم الـ Kernel trick لرفع البيانات إلى فضاء ذي أبعاد أعلى لتصبح قابلة للفصل خطياً Map data into a higher-dimensional space for linear separability.
  • خدعة صح وغلط شهيرة: عبارة Allows SVM to perform non-linear classification in the original feature space إجابتها False لأن الفصل يتم في الفضاء الأعلى أبعاداً وليس الفضاء الأصلي.
  • أنواع الـ Kernels الشائعة: تشمل Linear kernel و Polynomial kernel و RBF kernel (الذي يرفع البيانات إلى فضاء لا نهائي الأبعاد Infinite-dimensional space True). بينما Convolutional kernel ليس من أنواع الـ SVM!
